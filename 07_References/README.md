# References

This folder contains the academic references used to support the proposed research on machine learning-based intrusion detection for automotive CAN bus networks.

The references include studies related to:
- CAN bus security
- Machine learning-based intrusion detection
- Deep learning-based intrusion detection
- Automotive CAN bus datasets
- Cross-vehicle evaluation
- Intrusion detection performance metrics

All references used in the research proposal are formatted according to APA 7th edition.
