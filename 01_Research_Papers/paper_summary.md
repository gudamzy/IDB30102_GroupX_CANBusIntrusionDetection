# Research Paper Summary

The following studies were reviewed to support the proposed research on machine learning-based intrusion detection for automotive CAN bus networks.

## 1. Alalwany and Mahgoub (2022)
This study evaluated machine learning techniques for detecting normal and malicious CAN bus traffic. The findings showed that machine learning models can achieve high detection performance for CAN network intrusion detection.

## 2. Bari et al. (2023)
This study compared different machine learning approaches for intrusion detection in vehicle CAN bus networks. The results showed that traditional machine learning models can provide strong classification performance.

## 3. Ben Othmane et al. (2022)
This study evaluated CAN bus attack detection using data from a real moving vehicle. The study is important because it showed that intrusion detection performance in realistic conditions can differ from controlled experimental results.

## 4. Xiao et al. (2024)
This study investigated intrusion detection across different vehicle datasets. The results showed a noticeable performance reduction when a model trained using Hyundai data was evaluated using Chevrolet data, highlighting the cross-vehicle generalisation problem.

## 5. Lampe and Meng (2024)
This study introduced the can-train-and-test dataset. It contains CAN bus data from four vehicles from two manufacturers and includes multiple attack types. This dataset is relevant to the proposed research because it supports multi-vehicle and cross-vehicle evaluation.

## Relevance to Proposed Research

These studies show that machine learning can provide strong CAN bus intrusion detection performance. However, there is still limited evidence about whether models trained on one vehicle can maintain their performance when tested on another vehicle. This issue provides the main motivation for the proposed cross-vehicle evaluation.
