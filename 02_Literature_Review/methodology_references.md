## References Supporting the Methodology

The methodology used in this project is supported by the following references:

- **Wohlin, C., et al. (2012). _Experimentation in Software Engineering_. Springer.**  
  This reference was used as a guide for the experimental process, particularly in defining the variables, controls, and measurements before conducting the experiments.

- **UniKL MIIT (2026). _Research Methodology Selection Handbook_.**  
  Based on the handbook, the **Experimental** methodology is suitable for Group X. Since this project focuses on conducting experiments rather than developing a new system, the development model is stated as **“Not Applicable.”**

- **Lampe, B., & Meng, W. (2024). _can-train-and-test_.**  
  This work supports the testing setup used in the project. It uses fixed known and unknown vehicle subsets to evaluate both **same-vehicle** and **cross-vehicle** testing, which is relevant to the experimental design used in this study.
