# Results or Expected Output

This folder contains the expected output of the proposed cross-vehicle evaluation of machine learning-based intrusion detection models for automotive CAN bus networks.

At the proposal stage, the full experiment has not yet been conducted. Therefore, the results presented in this folder represent the planned evaluation structure rather than final experimental results.

## Expected Evaluation Output

The performance of Random Forest, Decision Tree, and Support Vector Machine will be evaluated under two settings:

- Same-vehicle evaluation as the baseline.
- Cross-vehicle evaluation using data from different vehicles.

The following performance metrics will be recorded:

- Accuracy
- Precision
- Recall
- F1-score
- False-positive rate (FPR)

The final results will compare the performance of each machine learning model between same-vehicle and cross-vehicle evaluation. This comparison will help determine whether model performance decreases when the vehicle data used for testing is different from the training vehicle.

## Files

- `expected_results.md` – Proposed structure for recording and comparing the experimental results.

## Current Status

No final experimental results are reported at this stage. The values will be added after the complete cross-vehicle experiments have been conducted.
