# Results or Expected Output

This folder contains the expected output and future experimental results of the research.

The performance of Random Forest, Decision Tree, and Support Vector Machine will be compared under same-vehicle and cross-vehicle evaluation.

The evaluation will include:
- Accuracy
- Precision
- Recall
- F1-score
- False-Positive Rate

The results will be used to analyse how well each machine learning model performs when tested on CAN bus data from different vehicles.
