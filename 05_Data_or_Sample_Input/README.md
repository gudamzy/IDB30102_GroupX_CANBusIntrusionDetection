# Data or Sample Input

This folder contains information about the dataset and sample input used for the proposed research.

The study proposes to use the can-train-and-test dataset, which contains CAN bus traffic from multiple vehicles. The dataset will be used to prepare training and testing data for same-vehicle and cross-vehicle evaluation.

Due to dataset size, the full dataset may not be stored directly in this repository. Dataset information and sample data will be provided instead.
