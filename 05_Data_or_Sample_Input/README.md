# 05_Data_or_Sample_Input

## Real dataset (not uploaded)

| Item | Detail |
|---|---|
| Name | can-train-and-test |
| Source | Technical University of Denmark data repository |
| URL | https://data.dtu.dk/articles/dataset/can-train-and-test/24805533 |
| Paper | Lampe, B., & Meng, W. (2024). *Computers & Security, 140*, 103777. https://doi.org/10.1016/j.cose.2024.103777 |
| Size | About 1.4 GB |
| Vehicles | 2011 Chevrolet Impala, 2011 Chevrolet Traverse, 2016 Chevrolet Silverado, 2017 Subaru Forester |
| Format | CSV per capture; timestamp, arbitration ID, data field, label (1 = attack, 0 = attack-free) |
| Structure | `set_01`–`set_04`, each with `train_01` and four test subsets |
| Licence | Check the licence shown on the DTU page before use and cite the dataset |

| Sub-dataset | Known vehicle (train_01, test_01) | Unknown vehicle (test_02) |
|---|---|---|
| set_01 | 2011 Chevrolet Impala | 2016 Chevrolet Silverado |
| set_02 | 2011 Chevrolet Traverse | 2017 Subaru Forester |
| set_03 | 2016 Chevrolet Silverado | 2017 Subaru Forester |
| set_04 | 2017 Subaru Forester | 2011 Chevrolet Traverse |

**Intended use:** train on a 500,000-frame stratified sample of `train_01`; test on `test_01`
(same vehicle, baseline) and `test_02` (cross vehicle). `test_03` and `test_04` are not used.

The dataset is not copied into this repository: it is large and redistribution should follow its
licence. Download it with the link above.

## Synthetic sample (uploaded)

`synthetic/set_syn/` contains three captures generated by `04_Source_Code/make_synthetic_data.py`
(seed 7). It copies the folder layout and CSV columns of can-train-and-test.

| File | Frames | Attack frames |
|---|---|---|
| `train_01/vehicleA_mixed_train.csv` | 59,336 | 21,536 (36.3%) |
| `test_01_known_vehicle_known_attack/vehicleA_mixed_test.csv` | 42,649 | 14,299 (33.5%) |
| `test_02_unknown_vehicle_known_attack/vehicleB_mixed_test.csv` | 41,996 | 14,396 (34.3%) |

Vehicle A uses IDs 0x0C0–0x3FF and vehicle B uses 0x400–0x7F0. Each capture contains DoS,
fuzzing and spoofing. **This is not real vehicle traffic.** It exists only to test the code.
